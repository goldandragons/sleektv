Custom styles

Overrides everything above. Paste a Jellyfin web theme's @import url("…"); to borrow its colors and shapes, or write rules like the ones below. Not shown in the preview.

Supported rules 
:root     { accent; background; surface; text; font-scale }
header    { style: floating|solid|hidden; scale: 1.2; opacity: 60%; search: show|hide; clock: show|hide }
brand     { primary: "Sleek"; primary-color: #fff; secondary: "TV"; secondary-color: #e50914 }
hero      { display: none|block; height; title-size; rotate; source: continue|latest }
section   { title-size; spacing }
card      { width; radius; spacing; focus-scale; shape: portrait|landscape; titles: show|hide; badges: show|hide }
continue  { shape: portrait|landscape }
details   { title-size; cast: show|hide; similar: show|hide }
home      { rows: ContinueWatching, NextUp, Latest, Discover, Libraries; latest-count }
episodes  { layout: list|grid|row; columns; thumb-width; seasons: tabs|stacked; order: asc|desc; overview: show|hide }
player    { skip-intro: button|auto|off; skip-credits: button|auto|off; button-seconds }
subtitles { mode: jellyfin|default|always|forced|off; language: eng; size: 120%; color; background: outline|shadow|box|none; position: 10% }
