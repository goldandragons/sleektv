SleekTV

These settings control the SleekTV app on your Android TV. The app picks up changes the next time it returns to the home screen.

Home screen

Seerr

Connect Jellyseerr / Overseerr so the app can show a Request tab in Search and recommend titles to add on the home screen. The API key stays on this server; requests are made as each Jellyfin user, so their Seerr permissions apply.

As this Jellyfin server reaches it.
Seerr → Settings → General → API Key.
Save first, then test.

Custom styles

CSS-style overrides. Anything here is applied after the settings above, so it wins. Unknown properties are ignored.

Supported selectors and properties 
:root    { accent; background; surface; text; font-scale }
header   { style: floating|solid|hidden }
hero    { display: none|block; height; title-size; rotate }
section  { title-size; spacing }          /* row headers and gaps */
card     { width; radius; spacing; focus-scale; shape: portrait|landscape;
           titles: show|hide; badges: show|hide }
continue { shape: portrait|landscape }
details  { title-size; cast: show|hide; similar: show|hide }
home     { rows: ContinueWatching, NextUp, Latest, Libraries; latest-count }
episodes { layout: list|grid|row; columns; thumb-width;
           seasons: tabs|stacked; order: asc|desc; overview: show|hide }
player   { skip-intro: button|auto|off; skip-credits: button|auto|off;
           button-seconds }

Example:
:root    { accent: #1db954; background: #0b0b0b; }
hero     { height: 460; title-size: 52; }
card     { radius: 16; width: 170; focus-scale: 1.12; }
episodes { layout: grid; columns: 5; overview: hide; }
